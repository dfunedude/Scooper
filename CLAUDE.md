# Scooper

A single-file browser game (`index.html`) published with GitHub Pages from `main`.

## Workflow

- The owner has asked for changes to go straight to `main`: commit and push to `main` directly, with no pull request.
  If the session is set up to use a separate branch, push the work there and also push it to `main`.
- Bump `VERSION` and add an entry to the top of `PATCH_NOTES` in `index.html` for each player-facing update.
